# Health On Time - Saúde do Homem

Solução tecnológica para promoção da Saúde do Homem.

## Estrutura

- `html/` - Páginas HTML
- `css/` - Estilos CSS
- `public/` - Imagens e assets

## Como Usar

Abra `html/index.html` no navegador ou use um servidor local:

```bash
cd html
python -m http.server 8000
```

## Editar

Edite diretamente os arquivos HTML em `html/` e CSS em `css/styles.css`.
